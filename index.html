História dos computadores

A história da computação começa muito antes da eletrônica: ela nasce da necessidade humana de calcular e registrar informações. Desde o ábaco até os PCs atuais, o computador passou por várias gerações.

Linha do tempo

  1. Ábaco (≈ 2400 a.C.) — primeiro instrumento de cálculo de que se tem notícia, usado na Mesopotâmia.
  2. Máquina analítica de Charles Babbage (século XIX) — projeto que inspirou os computadores modernos. Ada Lovelace escreveu o primeiro algoritmo pensado para essa máquina.
  3. ENIAC (1946) — um dos primeiros computadores eletrônicos, ocupava cerca de 180 m2 e pesava em torno de 30 toneladas.
  4. Transistor e circuito integrado (1947–1958) — reduziram o tamanho e aumentaram a confiabilidade das máquinas.
  5. Microprocessadores e PCs (a partir de 1971) — popularizaram a computação pessoal.
  6. Web (1989–1991) — Tim Berners-Lee cria a WWW e muda a forma como acessamos informação.
“A máquina analítica tece padrões algébricos como o tear de Jacquard tece flores e folhas.”
— Ada Lovelace, 1843

Curiosidade: os computadores trabalham em base binária. Como 210 = 1024, dizemos que log2(1024) = 10 — ou seja, 10 bits conseguem representar 1024 valores diferentes.

O que são Clients?

Client (cliente) é o programa ou dispositivo que solicita um recurso a outro programa. Em outras palavras, é o “lado do usuário” da comunicação. Quando você acessa um site, seu navegador é o client.

Exemplos de clients

  • Navegadores: Chrome, Firefox, Edge, Safari;
  • Aplicativos de e-mail (Outlook, Thunderbird);
  • Aplicativos móveis que consomem uma API;
  • Programas de FTP ou de mensagens instantâneas.

O client envia uma requisição (request) e aguarda uma resposta (response). A comunicação entre client e server normalmente segue o protocolo HTTP.

O que são Servers?

Um server (servidor) é um computador ou software que fornece recursos, dados ou serviços a outros programas. Ele fica “escutando” requisições e responde a elas.

Antigamente era comum ver páginas com cores e fontes definidas diretamente na tag font. Hoje essa tag está recomendada obsoleta — usamos CSS para isso. Mesmo assim, ela ainda é reconhecida pelos navegadores.

Tipos comuns de servidores

  • Servidor web (Apache, Nginx);
  • Servidor de banco de dados (MySQL, PostgreSQL);
  • Servidor de arquivos;
  • Servidor de e-mail.

Observação: um mesmo computador pode hospedar vários servidores ao mesmo tempo, cada um em uma porta diferente.

Como é uma estrutura básica de um HTML?

Todo documento HTML segue uma estrutura mínima. Vamos ver cada parte, do nível mais geral ao mais específico — e é aqui que usamos as tags de título h3, h4, h5 e h6 como exemplo de hierarquia.

<!DOCTYPE html>

Informa ao navegador que o documento usa HTML5. Não é uma tag de conteúdo, apenas uma declaração.

<html>

Elemento raiz que envolve todo o documento. Recebe o atributo lang para indicar o idioma (ex.: lang="pt-BR").

<head>

Contém metadados: charset, viewport, título da aba, links para CSS, etc. Nada aqui aparece diretamente na página.

<body>

É o corpo do documento — tudo o que o usuário vê (textos, imagens, links) fica dentro dele.

Exemplo de esqueleto mínimo:

<!DOCTYPE html>
<html lang="pt-BR">
  <head><title>Minha página</title></head>
  <body><h1>Olá!</h1></body>
</html>

Entendendo a diferença entre listas ordenadas e não ordenadas

As listas organizam itens. A grande diferença está na semântica: a ordem importa ou não?

Lista ordenada — <ol>

Use quando a sequência dos itens é importante (passo a passo, ranking):

  1. Abrir o editor de código;
  2. Criar o arquivo index.html;
  3. Escrever a estrutura básica;
  4. Salvar e abrir no navegador.

Lista não ordenada — <ul>

Use quando a ordem não altera o significado (itens de uma compra, tags):

  • HTML;
  • CSS;
  • JavaScript.

Dica: as duas tags aceitam apenas <li> como filho direto.
