# Trilha HTML — Dio.me

## Módulo 01 — Primeiros Passos com HTML

Projeto desenvolvido como desafio do **Módulo I — Primeiros Passos com HTML** da trilha de HTML da [DIO](https://www.dio.me). O objetivo é criar uma página web utilizando uma estrutura básica de HTML e praticar as principais tags aprendidas durante as aulas.

---

## 📌 Sobre o projeto

A página apresenta um índice com os tópicos estudados no módulo e desenvolve cada um deles com conteúdo em português:

- História dos computadores;
- O que são *Clients*;
- O que são *Servers*;
- Estrutura básica de um documento HTML;
- Diferença entre listas ordenadas e não ordenadas;
- Links de referências.

O arquivo também utiliza **âncoras internas** para navegação entre o índice e as seções, além de links externos que abrem em uma nova aba.

---

## 🧩 Estrutura do projeto

```text
.
└── index.html
```

O projeto é composto por um único arquivo HTML, sem dependências externas, CSS ou JavaScript.

## ✅ Tags utilizadas

### Tags solicitadas no desafio

- [x] `<h1>` até `<h6>`
- [x] `<p>`
- [x] `<mark>`
- [x] `<small>`
- [x] `<i>`
- [x] `<u>`
- [x] `<strong>`
- [x] `<ol>`
- [x] `<ul>`
- [x] `<li>`
- [x] `<a>`
- [x] `<hr>`
- [x] `<sub>`
- [x] `<sup>`
- [x] `<blockquote>`

### Novas tags pesquisadas e aplicadas

- [x] `<font>` — utilizada apenas para fins didáticos, pois está obsoleta no HTML5;
- [x] `<del>` — indica texto removido ou substituído;
- [x] `<abbr>` — exibe a descrição de siglas ao passar o mouse;
- [x] `<p>` — reforçado como elemento base de parágrafos.

> **Observação:** a tag `<font>` está obsoleta e não deve ser usada em projetos modernos. Atualmente, a estilização deve ser feita com **CSS**. Neste projeto, ela foi incluída apenas para cumprir o desafio proposto.

---

## 🔗 Navegação

A página contém:

- Índice com links internos para cada seção;
- Link **“Voltar ao índice”** ao final de cada tópico;
- Links de referência com `target="_blank"` e `rel="noopener noreferrer"` para abrir em uma nova aba com segurança.

---

## ▶️ Como visualizar

1. Clone este repositório ou baixe o arquivo `index.html`;
2. Abra o arquivo diretamente em qualquer navegador moderno;
3. Navegue pelo índice e pelos links internos da página.

Não é necessário instalar nada.
